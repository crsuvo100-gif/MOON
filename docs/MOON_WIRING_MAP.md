# MOON — System Wiring Map & Operational Audit

Generated by the deep audit. Every entry below was verified against the **running
system** (real imports, real WebSocket round-trips, real tool/LLM execution) — not
code-existence claims.

## 1. Runtime entrypoints → main brain

| Entrypoint | Command | Wires to brain |
|---|---|---|
| Terminal/API server | `python main.py` / `python main.py terminal` → `uvicorn app.terminal_interface:app` (systemd: `moon-terminal.service`) | Serves `app.terminal_interface`, which holds the live `Orchestrator` (`orch`) and the WebSocket `/ws` + HTTP `/api/*` |
| Dashboard | `python main.py dashboard` | `run_dashboard(run_fn)` where `run_fn` calls `orch.run_task(...)` |
| TUI (in-process) | `python main.py tui` | `Orchestrator` directly (no HTTP) |
| Telegram bot | `app/services/telegram_bot.py` | `Orchestrator.run_task(task, on_event=...)` |
| Doctor (health) | `python main.py doctor` | imports `Orchestrator`, runs `setup()`, reports 16 subsystems |
| CLI task | `python main.py run "<task>"` | `orch.run_task(Task.create(...))` |

The **main brain** is `app/brain/orchestrator.py :: Orchestrator`. `run_task()` is
the full cognition loop; `quick_reply()` is the fast single-call path used by chat/
WS/voice. `setup()` wires every cognitive module, the model service(s), memory, the
tool manager, and the per-agent brains.

## 2. Main brain → subsystems (all wired, confirmed live)

`Orchestrator.setup()` instantiates and connects:

- **LLM**: local `LLMService` (Ollama `qwen2.5:1.5b`) + optional strong model + 3
  fallback backends (OpenAI / OpenRouter / HuggingFace). All gated by settings keys.
- **Embeddings** (`EmbeddingService`).
- **Memory** (`MemoryManager`): short-term + long-term + vector store + `KnowledgeBase`
  (skills indexed into it — 24 skills discovered).
- **Cognition**: `ContextBuilder`, `ReasoningEngine`, `Planner`, `Validator`,
  `SelfReflection`, `OutputFormatter`, `ErrorRecovery`, `KnowledgeConsolidator`
  (auto-learning, when enabled).
- **Tools** (`ToolManager` over `ToolRegistry`): **43 tools** registered, incl.
  terminal, python, file, web, recon, vuln-scanner, malware, HF-deploy,
  `capability_manager`, `global_connector`, telegram, etc. Plugins loaded via
  `plugins.loader`.
- **Agents**: **39 agents**; each gets its **own `AgentBrain`** wired to the main
  brain for two-phase validation. `AgentFactory` reports **177** agent definitions.
- **Connector** (`ConnectionGateway`): 2 peers (loopback `moon_local` + federation).
- **Session lock**: `SessionLock` (locked by default; unlocks via phrase).

Orb (brain core) reacts to **real brain events** via `handle(type:"event")` +
`handle(type:"workflow")`: severity tiers (calm/normal/working/dangerous/aggressive),
aspect aura (agent/skill/memory/capability/verification/personality/alert), per-agent
brain label, and `MATURITY %` persisted in `app/data/brain_stats.json`.

## 4. Cross-cutting channels (all feed the brain)

- **WebSocket `/ws`** — primary terminal/HUD channel.
- **WebSocket `/ws/agent/{id}`** and **`/ws/events`** — agent detail + raw event bus.
- **EventBus** (`app/runtime/event_bus.py`) — publishes TASK_CREATED, AGENT_SELECTED/
  STARTED/COMPLETED, TOOL_*, VERIFICATION_*, MEMORY_UPDATED, SKILL_UPDATED, ERROR,
  etc. Subscribed by the terminal → orb. Verified: events carry `severity`/`aspect`/
  `agent_id` live.
- **Voice engine** (`app/voice_engine.py`) — real TTS WAV (kokoro primary), routes to
  `speak()`; returns a valid WAV file (157 KB verified).
- **Skill system** (`app/runtime/skill_system.py` + `app/skills/*`) — 24 skills + builder.
