# MOON Cognitive Memory Architecture (Discovery Report)

## Overview
This document captures the current state of the MOON memory subsystem after the read‑only discovery phase. It records existing components, their responsibilities, and gaps that need to be filled to achieve the **Ultimate Cognitive Memory Infrastructure**.

### Existing Components
| Component | Location | Role |
|------------|----------|------|
| **MemoryRecord** | `app/memory/record.py` | Dataclass representing a memory entry – includes scopes, type, provenance, confidence, importance, versioning, sync state, trust, canonical flag, etc. |
| **Layer definitions** | `app/memory/layers.py` | `Layer` class and `LAYER_REGISTRY` map each `MemoryType` (working, short‑term, episodic, semantic, procedural, user, project, agent, shared) to retention policies (TTL). |
| **LocalMemoryStore** | `app/memory/store.py` | SQLite‑backed per‑type storage (`MOON_MEMORY_PATH`). Handles upsert, get, query, delete, health, purge/expire based on layer TTL. |
| **CloudMemoryStore (stub)** | `app/memory/cloud_store.py` | In‑memory placeholder that implements the abstract `MemoryStore`. Intended to be replaced with a real remote store (PostgreSQL/Neon). |
| **MemoryManager** | `app/brain/memory_manager.py` | High‑level orchestrator that coordinates short‑term, long‑term, knowledge‑base, episodic memory, graph, stats, and maintenance. Provides `remember`, `learn`, `recall`, `unified_search`, maintenance hooks, etc. |
| **FAISS utilities** | `skills/mlops/faiss/` (SKILL.md present) | Vector‑search library available but not yet integrated into the memory stack. |
| **Tests** | `tests/` | Existing tests cover basic store behavior (`test_spec7_agents_memory.py`, `test_enhanced_memory.py`). |
| **Configuration** | `pyproject.toml`, `app/config/constants.py` | Declares dependencies (`fastapi`, `uvicorn`, `pydantic`) and defines runtime constants. |

### Gaps Identified
- No real **cloud backend** for persistence (only stub). 
- No **vector store** integration (FAISS not wired). 
- Missing **MemoryPolicyEngine** for read/write/share permission enforcement. 
- No **SyncEngine** for push/pull and conflict resolution. 
- No **ContextEngine** to collect, rank, and compress memories for the Brain. 
- No **HealthService** endpoint exposing subsystem health. 
- No **backup/restore/export/import** utilities. 
- No **observability/metrics** (Prometheus counters). 
- API routes for new operations not yet exposed via FastAPI.
