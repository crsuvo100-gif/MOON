## 1. What is project MOON?
A self-hosted autonomous AI-agent system (`moon-ai-agent` v0.1.0) with its own
"brain" (orchestrator + per-agent brains), a 40-agent spec roster (39 live),
43 registered tools, long/short/episodic memory, a knowledge base, a Neural
Brain Command Center UI (HTML/Canvas2D terminal HUD), and a FastAPI backend.
Pure Python; no Python UI deps. Runs against a LOCAL Ollama model (qwen3:0.6b)
with cloud fallbacks.

## 3. Main entry point
`python -m uvicorn app.terminal_interface:app --host 0.0.0.0 --port 8777`
(via `main.py start`, which also ensures Ollama + default loopback peer).
`pyproject.toml` also exposes console script `moon = "main:main"`.

## 4. Agents (39 live / 40 spec)
Defined in `app/agents/spec_agents.py` (_SPEC_AGENTS list) → `register_spec_agents()`
idempotently registers AgentMetadata into `app/agents/registry.py` (get_registry()).
Built into `AgentCard`s by `app/brain/agent_registry.build_agents(tool_names)` with
per-agent allowed-tools + per-agent models (AgentModelManager binds qwen2.5:1.5b / 3b,
qwen2.5-coder:1.5b, etc.). Each agent gets a connected AgentBrain (episodic memory).
Live API `/api/agents` → 39 agents. Sample: `research` agent has 4 allowed tools.

## 5. Tools (43 registered)
Explicitly instantiated in `Orchestrator.setup()` (app/brain/orchestrator.py:268-289),
then `ToolManager(registry, enabled_tools=all, allow_dangerous=True)`.
Includes web_search, browser, terminal, file_manager, python_executor, database,
api_requests, ocr, pdf_reader, image_processing, system_command, model_management,
learning, unit/timezone/ip converters, object_track, autonomous_chain, multimodal_*,
telegram, google_workspace, recon, vuln_scanner, hardening_audit, log_analyzer,
malware_analysis, exploit_intel, system_info, powershell, docker, git, self_evolve,
model_pull, github_sync, capability_manager, global_connector, huggingface_deploy,
huggingface_tool. Plus plugins via `plugins.loader.load_plugins(registry)`.
Live API `/api/tools` → 43 tools.

## 6. Services
- **LLMService** (app/services/llm_service.py): OpenAI-compatible /v1/chat/completions
  client → local Ollama (qwen3:0.6b primary, qwen2.5/3b/8b, deepseek-r1 fallbacks).
  Thinking models kept ON with token headroom (verified: returns real content).
- **EmbeddingService** (app/services/embedding_service.py).
- **HFInference** (app/services/hf_inference.py): optional HuggingFace hosted inference.
- **TelegramBot** (app/services/telegram_bot.py): optional Telegram channel.
- **ConnectionGateway** (app/connector/gateway.py): global connector, registers
  `moon_local` loopback peer (LIVE connection verified).
- **CapabilityManager** (app/capability/manager.py): 1 capability registered (huggingface).
- **EventBus** (app/runtime/event_bus.py): wired into WS `/ws` (agent runs / tool calls
  / task lifecycle → HUD EVENTS timeline).
